# OpenClaw Wallet

> **Autonome Krypto-Wallet-Engine für automatisierte Systeme und AI-Agenten.**

## Ziele
- Keine Registrierung, kein KYC, keine zentralen Anbieter
- Vollständige Self-Custody
- Modulare Architektur, API-first
- Sicher durch auditierten `bdk`-Core, Python-Bindings

## Status
- Phase 1: Grundgerüst — in Arbeit
- Bitcoin on-chain als erste Chain
- REST/API über Unix Socket geplant

## Schnellstart
```bash
git clone https://github.com/rawinstinctai/openclaw-wallet.git
cd openclaw-wallet
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
```
